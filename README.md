# CoMega — React Router Website

A responsive, multi-page business website built using **React, Vite, and React Router DOM**. This project was created as a hands-on learning experience to understand client-side routing, reusable components, and multi-page website development in React.

## Pages

The website includes the following pages:

- **Home** — Landing page of the website.
- **About** — Information about the business.
- **Services** — Overview of the services offered.
- **Contact** — Contact form and information.
- **404 Page** — Custom page displayed for undefined routes.

## Built With

- [React](https://react.dev/) — JavaScript library for building user interfaces.
- [React Router DOM](https://reactrouter.com/) — Client-side routing and navigation.
- [Vite](https://vite.dev/) — Front-end build tool and development server.
- CSS — Styling and responsive layouts.

## Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have **Node.js** and **npm** installed on your system.

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/YOUR-USERNAME/comega-react-router-website.git
   ```

2. **Navigate to the project directory:**

   ```bash
   cd comega-react-router-website
   ```

3. **Install the dependencies:**

   ```bash
   npm install
   ```

4. **Start the development server:**

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in your terminal to view the website.

## Note

The contact form is currently a front-end demo. It displays a confirmation message when submitted but does not send or store form submissions.

This project was developed for learning and practice, with a focus on:
